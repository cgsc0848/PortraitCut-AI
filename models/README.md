# Model files

Model weights are not stored in Git.

Before enabling automated downloads or redistributing any checkpoint, verify:
- exact upstream model card and revision;
- model code and weight licenses independently;
- required companion files;
- checksums and expected file sizes;
- preprocessing and output semantics.

The application currently uses Hugging Face Transformers to load the pinned BiRefNet-HR-matting revision. See the security note in README.zh-CN.md.
